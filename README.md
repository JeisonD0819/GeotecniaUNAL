# 🌡️ Excavación Geotécnica - Sistema de Instrumentación

Proyecto de instrumentación para una excavación de 50 metros utilizando sensores DS18B20 y un microcontrolador ESP32 para adquisición y almacenamiento de datos de temperatura en campo.

---

# 📌 Objetivos

- Medición de temperatura en excavaciones profundas
- Adquisición de datos con ESP32
- Almacenamiento local usando microSD
- Alimentación autónoma mediante baterías y paneles solares

---

# ⚙️ Hardware utilizado

- ESP32
- Sensores DS18B20
- Módulo microSD
- Baterías Li-Ion 3.7V
- TP4056
- Paneles solares

---

# 🧠 Características

- Comunicación One Wire
- Calibración mediante ajuste lineal
- Registro de datos en microSD
- Sistema autónomo portátil
- Alimentación solar
- Monitoreo de temperatura en tiempo real

# ⚠️ Problemáticas encontradas

- Pérdida de señal en cables de 50 metros
- Limitaciones de conectividad WiFi institucional
- Necesidad de calibración individual de sensores
- Limitaciones de autonomía energética
